# 🎓 College Event Portal

## 📌 Project Overview

The **College Event Portal** is a responsive web-based application designed to provide students with easy access to college events and activities.

The portal allows students to view upcoming events, check event schedules, explore event photos, register for events, and contact the event organizers.

## 🎯 Objectives

* Provide information about upcoming college events.
* Display event dates, timings, and venues.
* Allow students to register for events online.
* Provide an event gallery.
* Provide contact information for event-related enquiries.
* Create a responsive and user-friendly interface.

## ✨ Features

* 🏠 **Home** – Welcome page with announcements and portal information.
* 🎉 **Events** – Displays upcoming college events with event details.
* 📅 **Schedule** – Shows event dates, timings, and venues.
* 📸 **Gallery** – Displays images related to college events.
* 📝 **Registration** – Allows students to register for an event.
* 📞 **Contact** – Provides event office contact information.
* 📱 **Responsive Design** – Works on desktop, tablet, and mobile screens.
* ✅ **Form Validation** – JavaScript validation for registration details.
* 🔗 **Navigation** – All pages are connected through the navigation menu.

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – DOM manipulation and form validation
* **Responsive Web Design** – Mobile-friendly layout

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the **College-Event-Portal** folder in **Visual Studio Code**.
3. Open `index.html`.
4. Right-click the file.
5. Select **Open with Live Server**.
6. The College Event Portal will open in your web browser.
7. Use the navigation menu to visit the different pages.

## 📝 Registration

The registration page collects:

* Student name
* Email address
* Phone number
* Department
* Selected event
* Additional message

JavaScript is used to validate the required information before submitting the form.

## 📱 Responsive Design

The portal uses CSS media queries to adjust the layout for:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet

The navigation, cards, gallery, tables, and forms adapt to different screen sizes.
